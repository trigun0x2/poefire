POESESSID cookie
How do I get it?
  1. Log in on pathofexile.com in your browser.
  2. Open developer tools (F12) → Application (Chrome/Edge) or Storage (Firefox) → Cookies → https://www.pathofexile.com.
  3. Copy the value of POESESSID (32 characters) and paste it above.
It's your whole logged-in session: never share it or show it on stream. poefire stores it only on this PC, readable by your Windows user, and never displays it again. Logging out of the website ends it; then paste a new one.
